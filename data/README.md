# Data Sources

Synthetic source-style data for financial feature engineering validation.

- `entities.csv`: 36 predictive feature records.
- `daily_metrics.csv`: 5,040 predictive feature-day metric rows.
- `source_events.csv`: 760 operational events, QA checks, experiments, and stakeholder asks.
- `recommended_actions.csv`: 220 candidate actions with effort and expected lift.
